# Images à fournir

Tant qu'un fichier est absent, le site affiche un bloc de remplacement neutre. Pour remplacer : déposer l'image **avec exactement le nom indiqué**, dans le dossier indiqué, puis actualiser la page. Aucun code à modifier.

| Fichier | Page | Sujet | Format conseillé | Texte alternatif utilisé |
|---|---|---|---|---|
| `accueil/hero-signalement.jpg` | Accueil, en-tête | Agent municipal inspectant un nid-de-poule | JPG, 1200 x 900 px (4:3), sujet centré | Agent municipal inspectant un nid-de-poule |
| `categories/voirie.jpg` | Accueil, types de problèmes | Route dégradée ou nid-de-poule | JPG, 800 x 500 px (16:10) | Illustration de la catégorie Voirie |
| `categories/ordures.jpg` | idem | Dépôt d'ordures sur un trottoir | JPG, 800 x 500 px | Illustration de la catégorie Ordures |
| `categories/eclairage.jpg` | idem | Lampadaire en rue | JPG, 800 x 500 px | Illustration de la catégorie Éclairage |
| `categories/eau.jpg` | idem | Caniveau bouché ou fuite d'eau | JPG, 800 x 500 px | Illustration de la catégorie Eau |
| `categories/autre.jpg` | idem | Problème divers (arbre tombé, panneau) | JPG, 800 x 500 px | Illustration de la catégorie Autre |
| `logo/logo.png` | En-tête de toutes les pages | Logo CITEVOX (déjà en place) | PNG recadré, environ 640 x 105 px | CITEVOX, retour à l'accueil |
| `logo/favicon.svg` | Onglet du navigateur | Icône (déjà en place) | SVG | |

Les images sont recadrées automatiquement (`object-fit: cover`). Photos libres de droits uniquement. Les photos envoyées par les citoyens vont dans `static/uploads/` (géré par le serveur : ne rien y déposer).
